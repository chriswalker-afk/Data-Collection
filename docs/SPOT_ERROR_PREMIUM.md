# Premium Spot the Error — diagnostic workshop
The prior two-radio quiz was replaced with three linked independent decisions: locate a numbered flawed instruction, select a mathematical correction, and identify its consequence. Case-file cards and choices are native radio inputs for touch, keyboard, assistive technology and reduced motion.

All 15 audited situations now contain one correct consequence and two plausible distractors. The non-integer systematic and stratified rounding cases were sharpened so only one instruction is flawed. The original 15 repair identifiers, method mappings, difficulty levels and progress schema are retained.

Only the **first complete submission** records one answer for the relevant sampling-method concept. Full correctness requires all three dimensions; feedback explains each after checking. Missed cases are offered in a separate review round that **does not write any progress or session credit**. End-of-round summaries show independent location, correction and consequence counts.

Checks: content validation, unit diagnostics across all three dimensions, browser checks for delayed feedback, keyboard, five viewport widths, exact-once scoring, no-credit review, and other activity regression suites.
